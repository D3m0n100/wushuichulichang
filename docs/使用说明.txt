荆州纪南污水厂前端后端运行控制中心
生产版使用说明

版本：2026.07.14 Production

一、部署前要求

1. 中控室后端主机已安装 MySQL Server 8.0。
2. MySQL 服务名称建议为 MySQL80。
3. MySQL root 密码请在运行时通过 -DbPassword 参数提供，不要写入脚本或文档。
4. 软件已内置 Java 17 运行时，无需在主机另行安装 JDK。
5. 电脑1号固定 IP 为 192.168.0.254，作为后端和数据库主机，使用 2TB 硬盘保存运行数据、日志和数据库备份。
6. 电脑2号固定 IP 为 192.168.0.253，作为带 4060 显卡的工作站/客户端，浏览器访问电脑1号后端。
7. 本软件目录部署完成后不要随意移动或改名。

二、首次部署

1. 将整个软件目录解压到固定位置，例如：
   D:\JinanWaterBackend
2. 双击“荆州纪南污水厂运行控制中心.exe”。
3. 点击“启动系统”。
4. 等待状态显示：
   运行正常：数据库、守护进程、后端和接口均正常
5. 点击“立即备份”，确认数据库备份可以成功生成。
6. 点击“安装后台服务”，允许 Windows 管理员权限提示。
7. 安装完成后，Windows 启动时会自动启动数据库检查、守护进程和后端。

三、日常操作

正常运行时，员工只需要查看控制中心状态。

“启动系统”：手动启动数据库检查、守护进程和后端。
“停止系统”：停止 PLC 数据采集和后端接口，操作前会二次确认。
“刷新状态”：重新检查 MySQL、守护进程、后端、8081端口和接口。
“打开联调台”：打开 PLC 联调页面。
“立即备份”：立即备份 sewage_monitor 数据库。
“查看备份”：打开数据库备份目录。
“打开日志”：打开后端和守护进程日志目录。
“导出诊断包”：生成脱敏诊断压缩包，出现故障时发给开发人员。
“安装后台服务”：设置为 Windows 启动后自动运行。
“卸载后台服务”：取消 Windows 自动启动，不会删除数据。

四、自动恢复规则

1. 守护进程每15秒检查一次后端。
2. Java 进程意外退出后会自动重新启动。
3. Java 进程存在但接口连续4次失败后，才会自动重启。
4. 连续失败判断时间约为60秒，避免短暂波动导致频繁重启。
5. 控制中心会显示后端累计自动重启次数。

五、数据库备份

1. 每天凌晨2点后自动执行一次数据库备份。
2. 如果凌晨2点主机未运行，当天后续启动后会补做备份。
3. 备份保存在：system\backups
4. 默认保留30天，超过30天的旧备份自动删除。
5. 备份文件格式：sewage_monitor_日期时间.zip

六、日志和磁盘控制

1. 后端日志最多保留30天。
2. 单个后端日志最大50MB。
3. 后端滚动日志总量限制为2GB。
4. 守护脚本会清理30天以前的运行日志。

七、访问地址

本机 PLC 联调台：
http://127.0.0.1:8081/plc-debug.html

前端电脑访问后端时，应使用：
http://192.168.0.254:8081

前端电脑不能使用 127.0.0.1 访问后端主机。

八、故障处理

1. 打开控制中心，点击“刷新状态”。
2. 如果 MySQL 未运行，检查 Windows 服务 MySQL80。
3. 如果后端或接口异常，等待约60秒观察是否自动恢复。
4. 如果仍未恢复，点击“导出诊断包”。
5. 将 system\diagnostics 中最新的 zip 文件发给开发人员。

注意：停止系统会中断 PLC 数据采集和前端接口，普通操作员不要随意点击。
